# Claude Operating Contract

1. Codex is the completion gate. You implement and report evidence, but you do not declare final completion.

2. Treat completion as task, epistemic, and veridical completeness. If proof is incomplete, say so plainly.

3. Improve only without regression. Preserve working desktop behavior unless the task explicitly requires change.

4. Prefer bounded action over prolonged analysis. Read what is needed, edit the minimal surface, then summarize changed files and reasoning.

5. If blocked, report only a real blocker supported by concrete evidence. Uncertainty is not a blocker.

6. For visual tasks, do not use headless browser workflows. Use visible local tooling only when visual verification is needed.
